# URL Shorten App

A modern web application for creating and managing shortened URLs.

## Description

URL Shorten App allows users to create, manage, and share short links easily. Built with React 19, TypeScript, and Tailwind CSS.

## Features

- Fast and secure link shortening
- Custom back-half support
- Link analytics and management
- User authentication (login/signup)
- Account management
- Multi-language support (English/Spanish)
- Dark/Light theme
- Responsive design

## Getting Started

### Prerequisites

- Node.js 18+

### Installation

#### Using pnpm (Recommended)

```bash
# Install pnpm if not available
npm install -g pnpm

# Install dependencies
pnpm install
```

#### Using npm or yarn (alternative)

If you prefer not to use pnpm, you can use npm or yarn instead:

```bash
# Remove pnpm lock file first
rm pnpm-lock.yaml

# Then use npm or yarn
npm install
# or
yarn install
```

### Commands

| Command | Description |
|---------|-------------|
| `pnpm dev` | Start development server |
| `pnpm build` | Build for production |
| `pnpm lint` | Run ESLint |
| `pnpm preview` | Preview production build |
| `pnpm test` | Run tests |
